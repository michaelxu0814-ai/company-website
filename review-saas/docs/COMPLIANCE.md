# 合规清单（澳洲）

> 这是工程与运营必须遵守的底线，不是法律意见。上线前由澳洲律师审阅；条款或日期如有更新，以监管机构原文为准，并同步更新本文件。

## 1. 反垃圾信息法（Spam Act 2003，ACMA 执法）

邀评短信/邮件视为商业电子信息。每条消息必须满足：

- [ ] **同意（Consent）**：联系人记录必须有 `consent_source`（如 `job_completed`、`csv_import_attested`、`webhook`）和 `consent_at`。CSV 导入与 Webhook 接入时，商家需勾选/声明“这些客户与我有交易关系并同意接收联系”，声明内容与时间写入 `audit_log`。
- [ ] **身份（Identify）**：消息中出现商家名称；邮件页脚含商家联系方式。
- [ ] **退订（Unsubscribe）**：每条短信含 `Reply STOP to opt out`；每封邮件含退订链接与 `List-Unsubscribe`/`List-Unsubscribe-Post` 头。退订须立即生效（法定上限 5 个工作日，我们的目标 < 1 分钟），且不收费、无需登录。
- [ ] 退订关键词识别（不区分大小写，去除空白）：`STOP, STOPALL, UNSUBSCRIBE, CANCEL, END, QUIT, OPTOUT, OPT OUT`。
- [ ] 发送前检查 `suppressions`，命中则状态记为 `skipped`，原因记为 `suppressed`。
- [ ] 不购买、不导入来源不明的名单。

## 2. 澳洲消费者法与 ACCC 网络评价指南

- [ ] **不筛选**：所有收件人收到同一个 Google 评价链接，不做“满意才引导去 Google”的流程。代码中不存在按评分分流的分支。
- [ ] **不诱导**：模板禁止出现奖励换评价的表述。保存模板时检测关键词（`discount, voucher, gift card, free, prize, win, % off, reward`），命中则阻止保存并提示。
- [ ] **不代写、不伪造**：系统不生成“顾客评价”内容；AI 只用于商家对评价的**回复**。
- [ ] **不压制差评**：不提供“举报/删除差评”服务；AI 回复差评时语气专业、不攻击顾客、不泄露隐私。
- [ ] 销售与官网文案中不承诺“只要好评”“保证 X 星”。

## 3. Google 政策

- [ ] 遵守 Google 评价内容政策（禁止奖励、筛选、利益相关者评价）。
- [ ] Google Business Profile API 仅在获批后使用；遵守其服务条款与配额。
- [ ] OAuth 令牌加密存储；商家断开连接时删除令牌。

## 4. 隐私（Privacy Act 1988 / 澳大利亚隐私原则 APPs）

即使我们可能适用小企业豁免，也按 APPs 设计：

- [ ] 只收集必要字段：姓名、电话、邮箱、工单完成时间。不收集地址、工单金额等非必要数据（集成同步时丢弃）。
- [ ] 数据存储在澳洲区域（Supabase `ap-southeast-2`，Vercel `syd1`）。
- [ ] 隐私政策说明：收集什么、为何收集、谁会接触（Twilio、Resend 等子处理方）、境外传输情况、如何访问/更正/删除。
- [ ] 商家可删除单个联系人及其消息历史；账号注销后 30 天内删除数据（审计日志按法定/合同要求保留的除外，届时做去标识化）。
- [ ] 数据泄露应急：按《应报告数据泄露》（NDB）机制评估与上报，流程见运营手册的 SEV-1 部分。

## 5. 短信发送方名称

- [ ] 上线前核实 ACMA 短信发送方 ID 登记的现行要求与生效日期，以公司名义登记字母发送方名称；未登记前可用澳洲长号码发送。
- [ ] 每个商家可自定义发送方名称，但需经我们审核，且符合登记规则。

## 6. 税务与收费

- [ ] 价格以澳元标示并含 GST；Stripe 开具含 ABN 与 GST 的税务发票。
- [ ] 订阅条款明确：月付、可随时取消、试用期规则、退款政策。

## 7. 合规相关的自动化检查（CI 与值守）

- 单元测试覆盖：退订关键词、发送窗口、频控、筛选禁令（断言模板渲染结果中不存在条件链接）。
- 每日值守检查：过去 24 小时内是否有发给已退订地址的消息（应为 0，否则视为 SEV-1）。
